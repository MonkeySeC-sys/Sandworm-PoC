# Sandworm-PoC
A exploit designed to reboot a linux server / system. Sandworm only works on 32-bit linux systems. it looks for riscv32le, calling for a system reboot.
# Legality's
The author is not responsible for any damage caused by Sandworm, this is only for research and learning.
# How to patch this vuln
Upgrade to 64-bit, change your default passwords.
